隐私政策

您的照片始终保留在您的设备上。本页确切说明我们和我们的服务提供商会对您的信息做什么，以及不会做什么。

摘要

Image Converter Plus（以下简称“本应用”）由 Denys Lebiediev 开发。所有图像转换均在您的设备上运行。我们不运营任何接收您照片的服务器。但是，我们确实使用了少数受信任的第三方服务来处理应用内购买，并向免费用户展示可选的激励视频广告。这些服务会收集有限的、大部分为匿名的信息，详见下文说明。您始终可以掌控所发生的一切。

  • 您转换的照片和文件绝不会被上传——只有当您选择存储或分享时，它们才会离开您的设备。
  • Apple 处理购买。Adapty 帮助我们核实您的订阅状态。
  • 免费用户可以选择观看由 Google AdMob 投放的激励广告，AdMob 可能通过 Unity Ads 等中介合作伙伴展示该广告。
  • 如果您所在的地区要求广告同意表单，您将在展示任何广告之前看到此表单。
  • 如果我们曾要求获得追踪您以投放个性化广告的许可，您可以随时拒绝，本应用将继续以非个性化广告运行。

哪些内容保留在您的设备上

所有图像转换、调整尺寸、剥离元数据、文件命名、预设以及转换历史记录，完全在您的 iPhone 或 iPad 上进行。有关您照片内容的任何信息都不会传输给我们或任何第三方。

  • 您导入的照片和文件。
  • 从这些文件中提取或移除的元数据。
  • 输出的图像和 PDF。
  • 您的转换历史记录、预设和应用偏好设置。

您可以随时删除这些数据，方法是在历史记录标签页中移除项目、从设置中清除历史记录，或删除本应用。

第三方服务收集的信息

本应用依赖少数服务来实现其功能。我们已将每一项服务配置为仅收集必要的最少量数据。我们无法通过其中任何一项服务访问您照片的内容。

Apple StoreKit（购买）。 所有应用内购买 — 订阅、终身升级和打赏 — 均由 Apple 处理。Apple 向您的 Apple ID 收费，我们收到一份匿名的交易确认。我们绝不会看到您的姓名、电子邮件地址、账单地址或付款方式。如果您向 Apple 申请退款，本应用会与 Apple 共享与您的应用内购买相关的有限使用数据——例如您在本应用内的购买和退款记录、帐户存续时间，以及综合使用信号——以帮助 Apple 决定是否处理您的退款申请。我们不会共享任何照片、文件或个人信息。

Adapty（订阅管理）。 我们使用 Adapty 来核实您是否拥有有效的订阅或终身购买。Adapty 会收到由其 SDK 生成的匿名的设备范围标识符，以及核实您购买所需的 App Store 交易信息、应用版本和基本设备特征（操作系统版本和设备型号）。Adapty 不会收到您的 Apple ID、您的电子邮件地址或您照片的内容。请参阅 adapty.io/privacy。

Google AdMob 和 User Messaging Platform（激励广告，仅限免费用户）。 免费用户可以选择观看激励视频广告，以解锁一次批量转换。Pro 用户绝不会看到广告。展示广告时，Google AdMob 会收到应用标识符、基本设备特征、广告标识符和有限的互动事件（广告展示、点击、完成）。在您所在地区有此要求时（例如欧洲经济区、英国、瑞士以及美国部分地区），Google’s User Messaging Platform 会在加载任何广告之前向您展示同意表单；您可以拒绝并继续使用本应用。此外还会使用 Apple’s SKAdNetwork 来匿名归因广告效果。请参阅 policies.google.com/technologies/ads。

Unity Ads（广告中介）。 为了填充激励广告，Google AdMob 使用中介，这意味着某一条广告可能由合作伙伴网络而非 Google 自身提供。Image Converter Plus 集成了由 Unity Technologies 提供的 Unity Ads 作为中介合作伙伴。当 Unity Ads 提供广告时，它会收到上述相同的有限的、大部分为匿名的信息 — 广告标识符、基本设备特征以及展示和完成等广告互动事件 — 并尊重您通过 Apple’s App Tracking Transparency 提示和 User Messaging Platform 表单所做的相同同意选择。任何广告网络都不会收到您的照片、文件或转换活动。请参阅 unity.com/legal/privacy-policy。

广告网络可能会根据您的 IP 地址估算大致位置。Image Converter Plus 本身绝不会访问您的位置信息。

Apple App Store（更新检查）。 本应用会定期查询 Apple 的公开 iTunes Lookup 端点，以了解是否有更新版本可用。此请求仅包含本应用的 bundle 标识符和您的店面所在国家/地区。Apple 可能会在任何 HTTPS 请求中收到您的 IP 地址，但我们不会。

追踪与个性化广告

如果您是免费用户，在本应用首次能够向您展示广告时，我们可能会通过 Apple 的标准系统提示（App Tracking Transparency）询问您是否允许本应用使用您设备的广告标识符（IDFA）来投放更相关的广告。您可以随时在 iOS 设置 › 隐私与安全性 › 跟踪 › Image Converter Plus 中更改您的回答。

  • 如果您选择允许跟踪，AdMob 及其中介合作伙伴可能会使用您设备的广告标识符来展示个性化广告。
  • 如果您选择要求 App 不要跟踪，则仅会展示非个性化的情境广告。
  • Pro 用户完全不会看到广告，也绝不会被询问追踪问题。

在受 GDPR 或类似法律涵盖的地区，User Messaging Platform 同意表单会在加载任何广告之前出现，您之后可以在本应用内的设置  › 管理广告选择中查看或更改您的选择。

您的照片和文件

本应用通过 Apple 的隐私保护选取器（PHPickerViewController）访问照片，这意味着我们只能看到您明确选择的项目 — 而非您的整个照片图库。您从文件 App 导入的文件会直接从您选择的位置读取。转换后的图像会写入本应用内的私有文件夹、您的照片图库（经您许可）或您在文件 App 中选取的位置之一。

如果您授予本应用向您的照片图库添加内容的许可，本应用会请求最低限度的“仅添加照片”权限，因此它绝不会读取您现有的照片。

共享扩展

共享扩展让您无需打开 Image Converter Plus 即可从任何其他 App 转换图像。所选图像会在您的设备上本地处理。共享扩展不包含应用内购买、广告或分析。如果您点按共享扩展内的升级入口，主应用会打开，升级流程会在那里运行。

支持电子邮件中的诊断信息

当您点按本应用内的联系链接时，您的默认邮件 App 会打开一封草稿邮件，其中已预先填入基本诊断信息：应用版本、iOS 版本、设备型号、应用语言、订阅状态和可用磁盘空间。在您发送之前，该邮件对您完全可见。除非您按下发送，否则不会传输任何内容。

数据留存

我们不运营服务器，因此我们这边没有任何内容需要留存。文件、历史记录、预设和偏好设置存在于您的设备上，并会在您删除它们或卸载本应用时被移除。Apple、Adapty、Google 和 Unity 会根据各自的留存政策留存上述有限的信息；详情请查阅其隐私声明。

隐私清单

本应用附带一份 Apple 要求的隐私清单，确切声明它使用了哪些平台 API，以及其第三方 SDK 可能收集哪些数据类别。具体而言，该清单声明：与第三方广告关联的设备标识符和广告数据（由 AdMob 及其中介合作伙伴 Unity Ads 使用，仅在您授予许可时）；与分析和应用功能关联的产品互动、性能数据和其他诊断数据（由 Adapty、AdMob 和 Unity Ads 匿名使用）；以及与应用功能和分析关联的购买历史（用于核实您的订阅）。Apple 会将这些声明以及我们第三方 SDK 的清单汇总到 App Store 商品页的“App 隐私”部分。因此，该页面还会显示各 SDK 自身清单所声明的类别，例如粗略位置（根据您的 IP 地址估算）和崩溃数据。

儿童隐私

Image Converter Plus 并非面向 13 岁以下儿童（或您所在国家/地区的相应最低年龄以下儿童）。我们不会在知情的情况下收集儿童的个人信息。如果您认为某位儿童通过任何第三方服务向我们提供了个人信息，请联系我们，我们将与相关提供商合作以将其移除。

您在欧洲经济区、英国和瑞士的权利

如果 GDPR 或 UK GDPR 适用于您，您有权访问、更正、删除或导出您的个人数据，限制或反对某些处理，并向您当地的数据保护机构提出投诉。由于本应用仅在您的设备上处理您的照片和转换历史记录，您可以直接在本应用内自行行使访问、更正和删除权。对于由 Apple、Adapty、Google 或 Unity 持有的数据，请直接联系这些公司。您也可以写信至下方地址，我们将协助您转送请求。

我们所依据的法律依据是：履行合同（提供本应用和您的购买）、同意（针对个性化广告，同意通过 User Messaging Platform 和 App Tracking Transparency 征求）以及合法利益（保持本应用可靠所需的有限诊断信息，并与您的利益相权衡）。

您在加利福尼亚州的权利

如果您是加利福尼亚州居民，《加利福尼亚州消费者隐私法案》（CCPA/CPRA）赋予您以下权利：了解关于您收集了哪些个人信息，请求删除个人信息，更正不准确的个人信息，以及选择退出为跨情境行为广告而对个人信息进行的“出售”或“共享”。我们不出售您的个人信息。要选择退出为个性化广告进行的任何共享，请在 App Tracking Transparency 提示中选择要求 App 不要跟踪，或在 User Messaging Platform 表单中拒绝同意。要行使其他权利，请通过下方地址联系我们。

国际传输

Apple、Adapty、Google 和 Unity 可能会在您所在国家/地区以外的服务器上处理有限的信息，包括在美国。在法律要求的情况下，这些提供商依据标准合同条款或类似的传输机制。我们不运营自己的服务器，因此我们自身不会执行额外的国际传输。

本政策的变更

如果我们对本政策做出重大变更，我们将在此 URL 发布更新后的版本，并更新下方的“最后更新”日期。对于影响所收集数据的有意义的变更，我们将使用 App Store 更新说明来提请您注意该变更。

联系方式

任何第一方处理的数据控制者为 Denys Lebiediev。如果您对本隐私政策有疑问或希望行使您的权利，请写信至 imageconverterplus.help@gmail.com，我们将在 30 天内回复。
