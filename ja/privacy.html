プライバシーポリシー

お客様の写真はデバイス上にとどまります。このページでは、当社およびサービスプロバイダがお客様の情報をどのように扱うか、そして何を行わないかを正確に説明します。

概要

Image Converter Plus(以下“本アプリ”)は Denys Lebiediev によって開発されています。すべての画像変換はお使いのデバイス上で実行されます。当社はお客様の写真を受け取るサーバーを一切運用していません。ただし、アプリ内課金の処理および無料ユーザーへの任意のリワード動画広告の表示のために、少数の信頼できるサードパーティサービスを利用しています。これらのサービスは、以下に記載するとおり、限定的で大部分が匿名の情報を収集します。何が起こるかについて、お客様は常に管理権を持っています。

  • お客様が変換する写真およびファイルがデバイスから外に出ることは決してありません。
  • Apple が購入を処理します。Adapty はお客様のサブスクリプション状態の確認に役立ちます。
  • 無料ユーザーは、Google AdMob によって配信されるリワード広告の視聴を選択できます。AdMob は、Unity Ads などのメディエーションパートナーを通じて広告を表示する場合があります。
  • 広告同意フォームが必要とされる地域にお住まいの場合、広告が表示される前にフォームが表示されます。
  • パーソナライズ広告のためにお客様をトラッキングする許可を当社が求めることがあった場合、お客様はいつでも拒否でき、本アプリは非パーソナライズ広告とともに引き続き動作します。

デバイス上にとどまるもの

すべての画像変換、サイズ変更、メタデータの除去、ウォーターマーク付与、ファイル名の付与、プリセット、および変換履歴は、すべてお使いの iPhone または iPad 上で行われます。お客様の写真の内容に関する情報が当社またはいかなる第三者にも送信されることはありません。

  • お客様がインポートする写真およびファイル。
  • これらのファイルから抽出または除去されたメタデータ。
  • 出力された画像および PDF。
  • お客様の変換履歴、プリセット、およびアプリ設定。

履歴タブで項目を削除する、設定から履歴を消去する、または本アプリを削除することにより、これらのデータをいつでも削除できます。

サードパーティサービスによって収集される情報

本アプリは、その機能のために少数のサービスに依存しています。当社は、各サービスが必要最小限のデータのみを収集するよう構成しています。当社は、これらのサービスのいずれを通じても、お客様の写真の内容にアクセスすることはありません。

Apple StoreKit(購入)。 すべてのアプリ内課金 — サブスクリプション、ライフタイムアップグレード、およびチップ — は Apple によって処理されます。Apple はお客様の Apple ID に請求し、当社は匿名の取引確認を受け取ります。当社がお客様の氏名、メールアドレス、請求先住所、または支払い方法を確認することは決してありません。

Adapty(サブスクリプション管理)。 当社は、お客様が有効なサブスクリプションまたはライフタイム購入をお持ちかどうかを確認するために Adapty を使用します。Adapty は、その SDK によって生成された匿名のデバイス単位の識別子とともに、お客様の購入の検証に必要な App Store の取引情報、アプリのバージョン、および基本的なデバイス特性(オペレーティングシステムのバージョンおよびデバイスモデル)を受け取ります。Adapty が、お客様の Apple ID、メールアドレス、または写真の内容を受け取ることはありません。adapty.io/privacy をご覧ください。

Google AdMob および User Messaging Platform(リワード広告、無料ユーザーのみ)。 無料ユーザーは、1 回のバッチ変換をアンロックするためにリワード動画広告の視聴を選択できます。Pro ユーザーが広告を目にすることは決してありません。広告が表示されると、Google AdMob はアプリの識別子、基本的なデバイス特性、広告識別子、および限定的なインタラクションイベント(広告の表示、クリック、完了)を受け取ります。お客様の地域で必要とされる場合(例えば EEA、英国、スイス、および米国の一部)、Google’s User Messaging Platform は、広告が読み込まれる前に同意フォームを表示します。お客様は拒否して本アプリの利用を続けることができます。広告のパフォーマンスを匿名で測定するために Apple’s SKAdNetwork も使用されます。policies.google.com/technologies/ads をご覧ください。

Unity Ads(広告メディエーション)。 リワード広告を配信するために、Google AdMob はメディエーションを使用します。これは、個々の広告が Google 自体ではなくパートナーネットワークによって提供される場合があることを意味します。Image Converter Plus は、Unity Technologies が提供する Unity Ads をメディエーションパートナーとして組み込んでいます。Unity Ads が広告を提供する場合、上記に記載したのと同じ限定的で大部分が匿名の情報 — 広告識別子、基本的なデバイス特性、および表示や完了などの広告インタラクションイベント — を受け取り、お客様が Apple’s App Tracking Transparency のプロンプトおよび User Messaging Platform のフォームを通じて行ったのと同じ同意の選択を尊重します。いかなる広告ネットワークも、お客様の写真、ファイル、または変換アクティビティを受け取ることはありません。unity.com/legal/privacy-policy をご覧ください。

Apple App Store(アップデート確認)。 本アプリは、より新しいバージョンが利用可能かどうかを確認するために、Apple’s の公開 iTunes Lookup エンドポイントに定期的に問い合わせを行います。このリクエストには、本アプリのバンドル識別子とお客様のストアフロントの国のみが含まれます。Apple は HTTPS リクエストの一環としてお客様の IP アドレスを受け取る場合がありますが、当社は受け取りません。

トラッキングとパーソナライズ広告

お客様が無料ユーザーである場合、本アプリが広告を表示できる状態になった最初の時点で、当社は Apple’s の標準的なシステムプロンプト(App Tracking Transparency)を通じて、より関連性の高い広告を配信するためにお客様のデバイスの広告識別子(IDFA)を使用することを本アプリに許可するかどうかをお尋ねする場合があります。お客様の回答は最終的なものです。お客様はいつでも iOS 設定 › プライバシーとセキュリティ  › トラッキング  › Image Converter Plus でこれを変更できます。

  • お客様が トラッキングを許可 を選択した場合、AdMob およびそのメディエーションパートナーは、パーソナライズ広告を表示するためにお客様のデバイスの広告識別子を使用する場合があります。
  • お客様が Appにトラッキングしないように要求 を選択した場合、非パーソナライズのコンテキスト広告のみが表示されます。
  • Pro ユーザーは広告をまったく目にすることがなく、トラッキングに関する質問をされることも決してありません。

GDPR または同等の法律が適用される地域では、広告が読み込まれる前に User Messaging Platform の同意フォームが表示され、お客様は後から本アプリ内の 設定  › 広告の設定を管理 から選択内容を確認または変更できます。

お客様の写真およびファイル

本アプリは、Apple’s のプライバシーを保護するピッカー(PHPickerViewController)を通じて写真にアクセスします。これは、当社がお客様の写真ライブラリ全体ではなく、お客様が明示的に選択した項目のみを目にすることを意味します —。ファイルアプリからインポートするファイルは、お客様が選択した場所から直接読み取られます。変換された画像は、本アプリ内のプライベートフォルダ、お客様の写真ライブラリ(お客様の許可を得て)、またはファイルアプリでお客様が選択した場所のいずれかに書き込まれます。

お客様が本アプリにお客様の写真ライブラリへの追加の許可を与えた場合、本アプリは、既存の写真を決して読み取ることがないように、最小限の “写真の追加のみ” の許可を要求します。

共有エクステンション

共有エクステンションを使用すると、Image Converter Plus を開くことなく、他のあらゆるアプリから画像を変換できます。選択された画像は、お使いのデバイス上でローカルに処理されます。共有エクステンションには、アプリ内課金、広告、または分析は含まれていません。共有エクステンション内のアップグレードのエントリーポイントをタップすると、メインの本アプリが開き、そこでアップグレードのフローが実行されます。

サポートメールに含まれる診断情報

本アプリ内の連絡先リンクをタップすると、お客様の既定のメールアプリが、基本的な診断情報をあらかじめ入力した下書きメッセージとともに開きます。診断情報には、アプリのバージョン、iOS のバージョン、デバイスモデル、アプリの言語、サブスクリプション状態、および利用可能なディスク容量が含まれます。メッセージは、送信する前にお客様に完全に表示されます。お客様が送信を押さない限り、何も送信されません。

データの保持

当社はサーバーを運用していないため、当社側で保持するものは何もありません。ファイル、履歴、プリセット、および設定はお使いのデバイス上に存在し、お客様がそれらを削除するか本アプリをアンインストールすると除去されます。Apple、Adapty、Google、および Unity は、上記に記載した限定的な情報を各社独自の保持ポリシーに従って保持します。詳細については、各社のプライバシーに関する通知をご確認ください。

プライバシーマニフェスト

本アプリは、どのプラットフォーム API を使用するか、およびそのサードパーティ製 SDK がどのデータカテゴリを収集する可能性があるかを正確に宣言する、Apple が要求するプライバシーマニフェストを同梱しています。具体的には、マニフェストは次のものを宣言しています。サードパーティの広告に関連付けられたデバイス識別子および広告データ(AdMob およびそのメディエーションパートナーである Unity Ads が、お客様が許可を与えた場合にのみ使用)、分析およびアプリの機能に関連付けられた製品インタラクション、パフォーマンスデータ、およびその他の診断データ(Adapty、AdMob、および Unity Ads が匿名で使用)、ならびにアプリの機能および分析に関連付けられた購入履歴(お客様のサブスクリプションの確認のために使用)。Apple は、これらの宣言と当社のサードパーティ製 SDK のマニフェストを集約し、App Store の掲載情報の “App のプライバシー” セクションに表示します。

子どものプライバシー

Image Converter Plus は、13 歳未満の子ども(またはお客様の国における同等の最低年齢未満の子ども)を対象としていません。当社は、子どもから個人情報を意図的に収集することはありません。子どもがいずれかのサードパーティサービスを通じて当社に個人情報を提供したとお考えの場合は、当社までご連絡ください。当社は、それを削除させるために該当するプロバイダと協力します。

EEA、英国、およびスイスにおけるお客様の権利

GDPR または UK GDPR がお客様に適用される場合、お客様には、お客様の個人データへのアクセス、訂正、削除、またはエクスポートを行う権利、特定の処理を制限または異議申し立てを行う権利、ならびにお客様の地域のデータ保護当局に苦情を申し立てる権利があります。本アプリはお客様の写真および変換履歴をお使いのデバイス上でのみ処理するため、お客様はアクセス、訂正、および削除の権利を本アプリ内で直接ご自身で行使できます。Apple、Adapty、Google、または Unity が保持するデータについては、それらの企業に直接ご連絡ください。また、以下の宛先まで当社にご連絡いただくこともでき、当社はリクエストの送付先の案内をお手伝いします。

当社が依拠する法的根拠は次のとおりです。契約の履行(本アプリおよびお客様の購入の提供)、同意(パーソナライズ広告について。同意は User Messaging Platform および App Tracking Transparency を通じて求められます)、ならびに正当な利益(本アプリを信頼性のあるものに保つために必要な限定的な診断情報。お客様の利益とのバランスがとられています)。

カリフォルニア州におけるお客様の権利

お客様がカリフォルニア州の居住者である場合、California Consumer Privacy Act(CCPA/CPRA)により、お客様には、お客様について収集される個人情報を知る権利、個人情報の削除を要求する権利、不正確な個人情報を訂正する権利、ならびにクロスコンテキスト行動広告のための個人情報の “販売” または “共有” をオプトアウトする権利があります。当社はお客様の個人情報を販売しません。パーソナライズ広告のためのあらゆる共有をオプトアウトするには、App Tracking Transparency のプロンプトで Appにトラッキングしないように要求 を選択するか、User Messaging Platform のフォームで同意を拒否してください。その他の権利を行使するには、以下の宛先まで当社にご連絡ください。

国際的なデータ移転

Apple、Adapty、Google、および Unity は、米国を含むお客様の国以外のサーバー上で限定的な情報を処理する場合があります。これらのプロバイダは、法律で要求される場合、標準契約条項または同等の移転メカニズムに依拠します。当社は独自のサーバーを運用しておらず、したがって当社自身が追加の国際的なデータ移転を行うことはありません。
